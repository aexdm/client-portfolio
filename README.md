# Portfolio Website

This project is a personal portfolio website developed for my client, a young filmmaker. The goal is to present their work, background, association, and skills through a clean, cinematic interface optimized for both desktop and mobile.

The design focuses on a minimal and narrative-driven experience, highlighting film projects and creative work in a structured and immersive layout.

---

## Overview

The website is structured as a single-page application with tab-based navigation. It includes:

- Home section introducing the filmmaker
- Profile section with personal background
- Projects section showcasing films and series
- Association section describing collaborative work
- Skills section presenting technical and creative abilities

Each section is dynamically handled through JavaScript for smooth transitions and modal interactions.

---

## Features

- Responsive design (desktop and mobile)
- Tab-based navigation system
- Project modal system with dynamic content rendering
- Skills progress visualization
- Custom cinematic UI styling
- Mobile-first navigation bar
- Lightweight vanilla JavaScript implementation

## Sections

### Home
Introduction section presenting the filmmaker and their main artistic intention.

### Profile
Personal biography, interests, and creative direction.

### Projects
A collection of short films and creative works, each accessible through an interactive modal with:
- Title
- Description
- Production details
- Status (in progress or completed)

### Association
Information about a collaborative audiovisual association, including roles, missions, and experience gained through group projects.

### Skills
A breakdown of technical and creative abilities such as directing, writing, editing, sound, and production roles.

---

## Purpose

The purpose of this portfolio is to present cinematic work in a professional and structured way, while maintaining a strong visual identity aligned with filmmaking and storytelling.

It is intended to evolve over time as new projects are completed and added.
